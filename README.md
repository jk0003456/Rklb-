# Rklb- Mosaic Archive

로켓랩(Rocket Lab) 관련 자료를 체계적으로 아카이빙하고,
모자이크 이론(Mosaic Theory) 방식으로 증거를 연결해 투자/리서치 가설을 평가하는
경량 웹 프로토타입입니다.

## 핵심 기능

- **Launch Schedule 스타일 UI**
  - rocketlaunch.org 일정 페이지 느낌의 밝은 카드형 레이아웃
  - 날짜 배지 중심의 가독성 높은 리스트 디자인
- **자료 아카이브 패널**
  - 출처, 태그, 날짜, 신뢰도 기반의 증거 카드 표시
  - 신뢰도순/최신순 정렬 + 검색 + 태그 필터
- **모자이크 보드 패널**
  - 특정 가설에 연결된 증거 자동 매핑
  - 연결 증거의 평균 신뢰도로 가설 점수 계산
- **재무지표 및 주가추이 패널**
  - 연도별 매출액(USD million) 선형 그래프
  - 연도별 매출원가율(COGS ratio) 선형 그래프
  - 일렉트론 연도별 평균 발사 주기(일) 선형 그래프
  - 재무 데이터 출처: Rocket Lab Form 10-K, Rocket Lab 공식 IR 자료
  - 월별 종가를 막대 그래프로 시각화
- **Neutron 개발 일정 & 최신 백로그 패널**
  - Rocket Lab 공식 사이트 로드맵 기준 Neutron 개발 마일스톤
  - 최근 실적 발표 기준 백로그 금액 표시
- **현재 진행중인 계약 및 입찰 패널**
  - 계약/입찰 단계와 일정, 예상금액 표시
- **인수 회사 및 moat 패널**
  - Rocket Lab의 주요 인수 사례와 경쟁우위 요약

## 실행 방법

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173` 접속.

## 파일 구조

- `index.html`: 화면 구조
- `styles.css`: UI 스타일
- `app.js`: 샘플 데이터, 정렬/필터/스코어링/시각화 로직
